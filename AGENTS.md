- Write all code and repository content you add or change in English, unless an exception applies.
- Read the relevant requirements and architecture decisions in `docs/` before making changes.
- Put application code in `src/` and test projects in `tests/`.
- Preserve existing API contracts unless the task requires a change.
- Run `pwsh -File scripts/verify.ps1` from the repository root and report which checks ran.
